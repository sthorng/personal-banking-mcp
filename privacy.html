Privacy notice

Personal Banking MCP is a private, single-user project maintained by the GitHub user sthorng. It is intended to query only the operator’s own bank accounts. It does not accept customers or offer a public banking service.

Current status

The current implementation uses synthetic bank data. Live banking access is not yet enabled. The following describes the intended handling of data when that integration is activated; these documents do not imply that a bank connection already exists.

Account data and purpose

After the operator grants read-only bank consent, the service is intended to retrieve account identifiers, account names, currencies, balances and transactions to answer the operator’s requests and calculate cash-flow summaries. The service does not initiate payments.

Storage and access

Balances and transaction history are not written to a database or other persistent application storage. They are held in a bounded, temporary memory cache. Default cache lifetimes are 60 seconds for balances and five minutes for transaction pages; the operator can configure them. Expired entries are removed on subsequent cache activity; process shutdown clears memory. Bank authorization changes must invalidate cached data.

Provider signing keys and authorization/session secrets must be secured separately from the data cache. The service does not collect or store bank login credentials. Remote access must be authenticated and restricted to the operator. Application logs must not contain credentials, balances, transaction details or request bodies.

External services

Enable Banking is the selected account-information provider. Bank authentication and consent occur through the provider and the bank. Their own data handling and retention rules apply; see Enable Banking’s privacy notice. The application’s temporary cache does not control upstream retention.

If the operator connects an AI assistant such as ChatGPT, tool responses containing requested account data will be shared with that assistant’s provider and handled under its policies and account settings. This is separate from the service’s own cache.

These static documents are hosted on GitHub Pages. GitHub handles hosting-related request information under its own privacy statement. The documents include no application analytics, forms, scripts or banking access.

Control and contact

The operator can stop the service, clear its cache and revoke bank consent through the bank or provider. Revoking consent does not itself delete information already handled by external services; their controls apply. For project contact, use the contact options published on the maintainer’s GitHub profile. Do not post bank details, credentials or other private financial information in public issues.
